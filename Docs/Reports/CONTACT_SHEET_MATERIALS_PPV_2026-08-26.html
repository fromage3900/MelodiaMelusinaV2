5. Gaps & drift

5.1 Dead references in legacy PPV scripts. build_ppv_nikkidream.py and portfolio_scene_integration.py:10-12 reference M_PP_ToonOutline and M_PP_StorybookVines_Inst which do not exist on disk. Running those scripts against the current tree will silently no-op the missing assets.
5.2 PPV color-grading overrides may still be on live actors. build_ppv_nikkidream.py wrote bloom/vignette/CA/grain + color-gain vector overrides on per-level PPV_NikkiDream actors. The newer scripts don't touch them. A re-run of apply_dream_candidate_ppv.py won't restore the project-wide-neutral default. The owner decision (2026-08-01) was: "scene-wide cohesion belongs on MPC_Melodia_Palette, not on this volume" — so the per-level overrides are technically residual but not breaking.
5.3 M_RhythmSurface_Pulse master exists but no documented surface uses it. File is on disk at Materials/Masters/M_RhythmSurface_Pulse.uasset but no grep match for the path inside the script tree beyond create_rhythm_materials.py. Likely the rhythm material build is incomplete; it should be either referenced or archived.
5.4 M_Glitter_* quartet has no instances in Instances/. 4 glitter masters but no MI children. The "Show_GlitterHalo" MI in Instances/NikkiHero/ is the only glitter instance in the tree. All other glitter work is done at the master level.
5.5 Musical Dream kit is additive only. New SMs use M_Master_Toon_Universal as the surface master (assigned at build_musical_dream_kit.py:1) and 8 new MIs parent existing toon MIs. No master edits, no new top-level pipeline, no new ToonProfile.
