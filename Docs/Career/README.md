### Two things to never get wrong in an outgoing draft

1. **Do not cite the MATH benchmark table.** The 100-task / 98.8% TCA figures were **withdrawn
   2026-08-19** and were never measured. The only real evaluation artifact is `eval_results.json`
   (one model, one task, 60.35%, 0% pass) — and even that run was invalidated by a harness
   defect. Cite the gate ledger and the two genuine local-model probe results instead.
2. **"Playable" is a gated claim.** The four shipping gates have PASS rows; the six orchestra
   convergence gates do not. Check `python Tools/echo_run.py status` before writing a status
   sentence, and say which you mean.
