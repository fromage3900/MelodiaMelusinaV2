## Why this is a genuinely strong fit (not just a generic pitch)
This is the one studio on the list where the *process* used to build this portfolio is directly relevant, not just the output. Concretely, and provably:
- This entire environment-art pipeline has been built through sustained agent-driven iteration — an AI system reading/writing live Unreal material graphs, Niagara systems, and PCG graphs, verifying its own work against compile/render state rather than trusting claims. That is a hands-on, daily-practice version of exactly the human-AI collaborative workflow Promethean AI is building a product around.
- Concrete, checkable deliverables from that process: a 685-node Substrate toon master material (`M_Master_Toon_Universal`, ~192 exposed parameters across 12 style families), a 140+ graph PCG production library, 61 hand-authored procedural SDF "math-art" materials (raymarched Klein bottle, Möbius strip, Mandelbulb, Penrose staircase — no textures), and a genuine (p,q) torus-knot Niagara VFX system built from real knot-theory math.
- Directly relevant personal narrative: comfortable directing an AI collaborator toward a specific aesthetic outcome, catching its mistakes (several real tool bugs — silent parameter-drop bugs, broken texture references — were caught and fixed this project, not blindly trusted), and iterating fast. That's the actual day-to-day skill "training the AI" requires.
