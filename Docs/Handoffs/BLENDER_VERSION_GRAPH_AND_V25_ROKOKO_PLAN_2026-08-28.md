## 4. ZBrush Sculpt Prep

### What You Need

| Tool | Purpose | Status |
|------|---------|--------|
| ZBrush 2024/2025 | High-poly sculpting | Need to check if installed |
| GoZ (ZBrush plugin) | Send meshes to/from ZBrush | Comes with ZBrush |
| Blender GoZ addon | Bridge Blender <-> ZBrush | Need to install |
| Decimation Master (ZBrush) | Reduce poly count for UE | Comes with ZBrush |
| UV Master (ZBrush) | Auto-UV for baked maps | Comes with ZBrush |
| Substance Painter | Texture painting | INSTALLED (you have .spp files) |

### ZBrush Sculpt Pipeline

```
[FinalUERig43.blend] ──GoZ──> [ZBrush] ──sculpt──> [High-poly mesh]
                                                         │
                                                         ▼
                                              [Decimation Master]
                                                         │
                                                         ▼
                                              [Low-poly mesh + normal map]
                                                         │
                                                         ▼
                                              [UV Master / UV unwrap]
                                                         │
                                                         ▼
                                              [Bake maps: normal, AO, curvature]
                                                         │
                                                         ▼
                                              [Substance Painter] ──paint──> [Textures]
                                                         │
                                                         ▼
                                              [Export to UE: mesh + textures]
```

### Sculpt Priorities for v25

1. **Melusina head** — highest detail (face, hair, expressions)
2. **Melusina body** — muscle definition, cloth folds
3. **Sir Melodious** — feather detail, beak, crest
4. **Choral Sheep** — wool texture, facial features
5. **Outfit pieces** — cloth folds, trim details, jewelry
6. **Perch props** — bark texture, moss, wear

### GoZ Setup for Blender

1. Install ZBrush 2024+
2. Install Blender GoZ addon (comes with ZBrush, in ZBrush installation folder)
3. In Blender: Edit > Preferences > Add-ons > Install > select GoZ addon
4. Configure GoZ path to ZBrush installation
5. Select mesh in Blender > click "GoZ" button > mesh opens in ZBrush
6. Sculpt in ZBrush > click "GoZ" button > mesh returns to Blender
