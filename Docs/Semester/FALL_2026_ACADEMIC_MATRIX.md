## Mapping rule

Prefer a Melodia artifact only when it genuinely satisfies the assignment.

Do **not** distort a course assignment to force everything into the game.

Good mappings should create at least two outputs from one effort, for example:

- character acting assignment → Melusina Starskiff departure shot → reel;
- environment assignment → Shorewake Quay hero scene → portfolio case study;
- material assignment → Shorewake cloth / pearl / water treatment → technical-art breakdown;
- modeling assignment → Starskiff instrument / hero prop → environment + breakdown.

## Intake checklist for each new brief

Record:

1. exact assignment wording;
2. grading weight;
3. due date and submission time;
4. rubric categories;
5. required software / technique;
6. individual vs group work;
7. resolution / duration / file format;
8. whether existing project work is permitted;
9. instructor-specific constraints;
10. the smallest strong Melodia deliverable that satisfies it.

## Semester priority score

When multiple assignments compete, prioritize by:

```text
academic urgency
× grade weight
× portfolio value
× reuse across Melodia
÷ production risk
```

The score is a decision aid, not a substitute for instructor requirements.
