# Shorewake Week 01 Art Sprint — Fall 2026

**Sprint start:** 2026-09-07
**Primary outcome:** a compelling blocked-and-lit Starskiff Mooring hero composition that establishes the semester's visual bar.

## This week's rule

**Composition before content. Lighting before micro-detail. One excellent frame before three average spaces.**

The semester does not need more systems this week.

## P0 — First art session

### 1. Open the existing scene

/Game/EnvSandbox/Monoliths/SeaAbove/Prototype/LV_SeaAbove_Prototype

Do not start by rebuilding the level.

### 2. Locate the real hero assets

Confirm in-editor:
- Melusina;
- Shorewake dress;
- Starskiff;
- mooring / lyre host;
- reef kit;
- cloth banner;
- PCG_SeaAbove_BellTreeGarden;
- PPV_NikkiDream.

If an asset is unavailable in the current checkout, record that as a portability issue instead of replacing it with a new system.

### 3. Build three cameras

Create temporary Sequencer/camera candidates:
- Processional 3/4;
- Intimate profile;
- Wide destination.

Capture all three before choosing one.

### 4. Brutal composition pass

For each candidate:
- hide nonessential actors;
- reduce PCG density if it muddies silhouettes;
- move large reef masses to frame the destination;
- reserve clean negative space around Melusina;
- make Starskiff unmistakable at thumbnail scale.

Do not texture-polish anything yet.

### 5. Establish one lighting rig

Start from the existing/certified environment and PPV stack.

Target:
- soft pearl key;
- cool Sea Above fill;
- warm Starskiff accent;
- readable Shorewake silhouette;
- dark-value structure survives without bloom.

## P1 — Material convergence

Only after one camera wins.

Shorewake dress:
- silhouette;
- fabric value separation;
- PearlWoven animation;
- shimmer frequency;
- StickerEdge;
- no swimming UV / frame-rate distraction.

Starskiff:
- separate hull, brass, cushion, and wake-light;
- brass should be the strongest warm accent in the frame.

Reef:
- remove equal-strength sparkle;
- prioritize silhouette and depth;
- use higher complexity near focal transitions, not everywhere.

## P2 — Environment authored detail

Once HERO 01 composition and materials are stable:
- build one designed mooring platform / landing read;
- add one memorable reef-frame motif;
- add one music-related prop/read near the lyre host;
- make the approach path visually obvious;
- use procedural tools only to accelerate these goals.

No broad Sea Above expansion this week.

## P3 — Motion proof

reef foreground reveal → Melusina → Starskiff destination.

No dialogue required. No gameplay logic required. No final animation required.
