## 1. Semester thesis

For Fall 2026, Melodia is not treated as an unlimited game-expansion project.

The semester production thesis is:

> **First Dream is the stable technical proof. Shorewake Calling is the semester production artwork.**

Every new task must produce at least one of:

1. a graded Humber deliverable;
2. a visible portfolio improvement;
3. a reusable production improvement required by 1 or 2;
4. a stability fix blocking 1 or 2.

Anything else goes to backlog.

## 4. First Dream rule

First Dream is now **protect-and-polish**, not a semester expansion lane.

Allowed work:

- regression fixes;
- packaged proof;
- clarity / presentation fixes;
- capture-quality improvements;
- professor-demo rehearsal.

Not allowed without a documented blocker:

- new gameplay frameworks;
- new save architecture;
- new global authorities;
- unrelated content expansion.

Its purpose is to demonstrate:

```text
music / challenge
→ reward
→ wardrobe
→ traversal capability
→ changed world access
→ checkpoint
→ save
→ process restart
→ restore without duplication
```

## 7. Weekly evidence packet

Every production week should leave:

- one beauty image;
- one detail image;
- one WIP / viewport image;
- one technical breakdown image or note;
- one 10–30 second animation/gameplay capture;
- one short note: what improved, what remains blocked.

Suggested local output:

`Saved/SemesterEvidence/YYYY-WW/`

Curated finals may later be promoted into a tracked portfolio/evidence path.

## 8. Presentation hierarchy

For academic and recruiter review:

1. **final image / animation first**;
2. artistic intent;
3. process / breakdown;
4. technical architecture only where it explains the result.

The project should read as the work of an environment designer / technical artist, not as a repository-maintenance demonstration.

## 9. Scope guardrails

- broad AI-agent infrastructure;
- speculative online/live-service systems;
