## 4. Root causes

### Cause A: Missing placement transforms
Every system was authored in local coordinates. The master join places all at origin. Need Transform nodes per-system with correct offsets.

### Cause B: Parametric overshoot
5 systems read height params from the wrong source (facade wave, parent scale, or no clamp). Need per-system height clamps.

### Cause C: Boolean junk
Door_Entry and Clef have 93 loose verts each from boolean operations that left detached geometry. Need "Delete Loose" or "Merge by Distance" cleanup.

### Cause D: Flat geometry
Window_Turret_S has zero height (z=[0,0]) — a node socket was never set. WalkStraight has zero thickness (z=[-0.21,-0.21]) — extrude offset was never applied.

### Cause E: Scale inheritance
NikkiQuarter and NikkiBloom were not half-scaled. The expansion script placed them at full scale. Need 0.5 scale transform.
