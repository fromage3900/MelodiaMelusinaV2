## Critical 5.2 lessons (carved in stone from prior sessions)

1. GN group param defaults live on tree.interface.items_tree (item.default_value), NOT the Group Input node output. Writing the node is a silent no-op.
2. Mesh Bevel uses Offset socket, NOT Radius. (5.2 API change)
3. CurveArc uses Sweep Angle socket, NOT Angle. (5.2 API change — mother_v3 curved builder is broken)
4. Per-object modifier inputs cannot be set headless. Bake params as interface defaults.
5. Kit builders stamp canonical MEL_* names via label_tree. Rename tree.name to GN_MH_* after building.
6. Instance accumulation via Repeat Zone is finicky. Prefer Instance on Points for shingles/balusters.
7. Boolean cutters must be realized ONLY on the boolean branch. Never realize the entire house.
8. Sample UV Surface is the ONLY correct way to project shingles onto curved roofs.
