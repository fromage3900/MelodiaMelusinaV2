## Purpose

This reference set exists to keep Blender, Unreal, TouchDesigner, and After Effects pointed at the **same visual target**.

It is intentionally narrower than a general Melodia moodboard.

Every reference must answer at least one production question:

- What makes the sheep lovable before VFX?
- What makes Chladni Fleece feel physically/musically grounded?
- How should a musical hit change scale and composition?
- What should TouchDesigner contribute that Unreal should not simply imitate?
- How should the final capstone film move between beauty, system, and spectacle?

## Capstone synthesis

The intended Melodia visual arc is:

```text
soft creature portrait
→ one hidden musical structure appears
→ musical relationship becomes visible
→ visual scale suddenly expands
→ world answers
→ return to intimate creature image
```

The concert references are not a request to turn Melodia into a rave.

They teach **dramaturgy**:

- restraint before impact;
- one clear silhouette;
- graphic scale jumps;
- large readable screen language;
- event-specific/localized visual moments;
- crowd/character response as part of the image;
- visual motifs that arrive on structural musical moments.

The Melodia translation remains:
- pearl;
- lavender;
- cool cyan;
- water-light;
- embroidery;
- cymatic geometry;
- storybook creature appeal;
- authored fantasy-world consequence.
