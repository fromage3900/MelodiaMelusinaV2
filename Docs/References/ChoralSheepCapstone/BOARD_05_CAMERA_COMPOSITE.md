# Board 05 — Camera + Final Composite

## Production question

**How do we turn the experiment into a short film that first sells character, then reveals the system?**

## Camera families

### Creature portrait
- 50–85 mm;
- face / ears / bell readable;
- shallow enough depth to feel intimate;
- Chladni effect can be absent.

### Fleece macro
- nodal embroidery visible between clumps;
- avoid macro shots so close that wool becomes abstract noise.

### C/E/G composition
- triangular staging;
- each sheep independently readable;
- use negative space for the shared TD field.

### World-answer wide
- small creatures;
- enormous response;
- clean silhouette;
- one stage-scale form dominates.

## Concert lesson

A powerful show frequently works because **the performer becomes tiny relative to one overwhelming visual event**.

Use that exactly once in the capstone.

Do not maintain “maximum spectacle” for the whole film.

## AE composite rule

Sequence the argument:

```text
FINAL BEAUTY
→ brief signal/data reveal
→ TD field
→ UE material integration
→ final composite
```

Then immediately return to the art.

## Breakdown vocabulary

Use restrained captions:
- CREATURE
- PITCH C
- HARMONY
- SHARED FIELD
- WORLD RESPONSE

Avoid software-first labeling in the opening.

## Final visual rhythm

1. quiet wool;
2. one pattern;
3. scale expansion;
4. one violent/clean rhythmic cut;
5. resolved world;
6. soft afterimage.

The last shot should make the sheep lovable again.
