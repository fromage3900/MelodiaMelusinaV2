# Board 02 — Chladni / Cymatic Pattern Language

## Production question

**What visual structure can honestly read as musical resonance rather than decorative magic?**

## Reference families

Use physically grounded studies of:
- Chladni plates;
- circular membrane modes;
- standing waves;
- interference;
- nodal lines;
- sand accumulation on nodes;
- water-surface cymatics;
- Lissajous / harmonic curve relationships as secondary references.

Useful public reference:
- Evoluteur cymatics / Chladni visual survey: https://evoluteur.github.io/cymatics/index.html

## KEEP

- low-order modes first;
- large nodal structure readable at thumbnail scale;
- increasingly complex organization as additional pitches enter;
- strong negative space between nodal bands;
- patterns with radial or bilateral logic;
- physical imperfection at transition moments.

## AVOID

- arbitrary mandalas with no relation to signal state;
- ultra-fine fractal noise;
- complexity that only reads at 400% zoom;
- brightness as the only indicator of harmony.

## APPLICATION — C → E → G

### C
One strong, calm modal identity.

### C + E
Interference becomes visibly more complex and less settled.

### C + E + G
The flock does not merely get brighter.

The key event is:

> **the shared field becomes more ordered and coherent.**

Use the same field vocabulary for:
- fleece;
- nearby water;
- pearl grass / reef;
- optional final route / mooring response.
