## Evidence rule

Reference board ≠ implemented asset.

When using these boards in documentation or presentations, distinguish:
- **reference / concept direction**
- **owner-authored source**
- **source present**
- **UE import / runtime verified**
- **final beauty / capture approved**

This keeps visual ideation ambitious without turning concept art into production claims.
