# Melodia Live Visual Identity Contract

**Status:** CURRENT — 2026-09-08  
**Applies to:** TouchDesigner live-performance / concert / capstone visuals  
**Primary rule:** **Steal the timing, not the branding.**

## 1. Purpose

TouchDesigner is allowed to make Melodia feel enormous, performative, rhythmic, and technologically alive.

It is **not** allowed to erase Melodia's authored visual identity.

Every TD scene must still look like it belongs to the same world as:
- Melusina;
- Choral Sheep;
- Sea Above;
- Shorewake;
- Starskiff;
- the project's pearl / cloth / water / musical-ornament language.

## 2. Visual hierarchy

Every performance frame should read in this order:

1. **subject silhouette** — creature / Melusina / destination;
2. **one primary musical structure** — Chladni ring, staff-line field, glyph, interference surface;
3. **supporting atmosphere** — water-light, pearl particulate, restrained bloom;
4. **secondary data / typography** only when structurally useful.

If an effect competes with the subject, reduce or remove it.

## 3. Core palette

Preferred:
- black-violet / deep indigo negative space;
- pearl white;
- pale sea cyan;
- lavender / periwinkle;
- dusty pink only as a restrained cloth/character accent;
- warm brass / candle-gold only as a focal counter-accent.

Forbidden as defaults:
- full-spectrum rainbow;
- generic cyberpunk RGB;
- permanent magenta/cyan split;
- full-frame acid/neon color cycling;
- red/black concert language copied from another artist.

Color changes should have musical or narrative meaning.

## 4. Material language

Prefer:
- pearl;
- wet light;
- satin;
- organza;
- embroidery;
- fine filigree;
- translucent membrane;
- lace-like nodal geometry;
- subtle iridescence;
- water refraction/reflection.

Avoid:
- chrome everywhere;
- generic hologram scanlines;
- plastic EDM glow;
- equal-frequency sparkle across the frame.

## 5. Motion law

**Stillness is part of the show.**

A Melodia TD scene must include hold/rest states.

Do not keep every layer moving continuously.

Preferred motion:
- slow breathing;
- held structures;
- sudden clean scale changes;
- phase locking;
- coherent expansion;
- one violent/clean rhythmic hit followed by recovery.

Avoid:
- permanent turbulence;
- constant camera shake;
- unbounded feedback drift;
- nonstop strobing;
- particles with no structural role.

## 6. Concert dramaturgy

Canonical show sequence:

```text
QUIET
→ ROOT HIT
→ INTERVAL HIT
→ RESOLUTION HIT
→ WORLD HIT
→ AFTERIMAGE
```

### QUIET
Subject first. Minimal field. Negative space.

### ROOT HIT
One huge, calm motif arrives.

For Choral Sheep: pitch C / one Chladni basis.

### INTERVAL HIT
A second voice introduces interference, split, or asymmetry.

### RESOLUTION HIT
The visual language becomes **more ordered**, not simply brighter.

### WORLD HIT
The effect crosses from graphic presentation into Unreal's authored world:
water / reef / material / architecture responds.

### AFTERIMAGE
Return to intimacy. Let the creature/person remain memorable.

## 7. Scale rule

Use **one major scale jump per sequence**.

Example:
tiny sheep → screen-filling harmonic field.

Do not keep everything monumental from frame one.

The contrast is the spectacle.

## 8. Typography / glyph rule

Typography is an event, not a HUD.

Allowed:
- C
- E
- G
- I / III / V
- HARMONIZE
- chapter-specific musical glyphs;
- extremely short semantic words tied to the scene.

Use:
- large scale;
- sparse placement;
- strong negative space;
- short duration;
- context-specific variation.

Avoid:
- paragraphs;
- debug labels in beauty shots;
- constant lyric overlays;
- copied artist/album logo language;
- random pseudo-Japanese / pseudo-tech text.

## 9. Effect budget

Per major musical event:
- **1 primary effect**
- **1 supporting effect**
- optional atmosphere

Examples:

GOOD:
- giant Chladni ring + subtle pearl motes.

BAD:
- Chladni + feedback + particle storm + RGB split + text + kaleidoscope + glitch + bloom blast.

## 10. Feedback / glitch rule

Feedback and glitch are punctuation.

Allowed:
- ROOT / INTERVAL transition;
- brief dissonance;
- phrase cut;
- memory fracture;
- concert-scale hit.

Not allowed:
- permanent default look;
- feedback simply because TouchDesigner can do feedback.

## 11. Bloom rule

Bloom supports light hierarchy.

It must not:
- erase wool;
- flatten the subject silhouette;
- turn every bright pixel into equal glare.

Post-FX should be bypassable and scene-independent.

## 12. Choral Sheep-specific law

Chladni Fleece must read as:

> **hidden pearlescent embroidery revealed by song**

Pitch changes **pattern structure**.

Amplitude changes **strength**.

Beat phase may change **breathing / pulse**.

Harmony resolution changes **coherence**.

Do not encode every state as brightness.

## 13. Agent veto checklist

Reject a proposed visual if any answer is YES:

- Does it look like generic VJ content?
- Could it belong to any cyberpunk game?
- Is the subject harder to read?
- Is there no quiet/rest state?
- Is rainbow color doing the conceptual work?
- Is feedback always on?
- Is the effect driven directly by raw audio with no semantic shaping?
- Does it copy a concert artist's branding rather than their timing/composition principle?
- Does it create a second gameplay/music authority?
- Is it impossible to reset deterministically?

If yes: simplify before building further.
