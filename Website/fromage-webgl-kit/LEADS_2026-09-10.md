## Prototype decision

Do **not** build ten bespoke samples.

Build three generic clean-room prototypes that answer multiple buyers:

### P-A — Web Product Motion Lab
Covers leads 1, 6 and much of 7.

- generic handheld/product-like owned geometry;
- web-optimized GLB loading path;
- scrub-safe named animation timeline;
- 3–4 named annotation anchors;
- PBR studio lighting;
- texture/geometry budget readout;
- scroll/timeline scrub demonstration;
- mobile-width QA.

### P-B — Fabric Material Lab
Covers leads 2 and 6.

- generic cloth/swatch geometry;
- several independently-authored PBR textile presets;
- live base-color / roughness / normal / sheen controls;
- texture swap and color variant system;
- optional user image decal on a generic garment/swatch surface;
- simple JSON state export;
- visually credible close-up camera.

### P-C — Procedural Industrial System Loop
Covers leads 3, 4, 5 and demonstrates SKU 5.

- procedural geometry only or owned primitives;
- deterministic seeded layout;
- strict one-axis-at-a-time mechanical motion mode;
- parameterized structural / flow / thermal visualization look modes;
- one displacement/shader transition variant;
- stable composition with restrained lighting;
- captureable 10–16 second loop;
- browser-performance readout.
