# Melodia Agentic Studio

**Canonical operating contract:** [`Docs/Production/AGENTIC_STUDIO_OPERATING_MODEL.md`](Docs/Production/AGENTIC_STUDIO_OPERATING_MODEL.md)

Read that document when assigning, routing, supervising, or reviewing AI/remote-agent work.

It does **not** replace the current production queue or discovery authority:
- immediate priority → `CAPSTONE_NOW.md`
- agent discovery/current state routing → `AGENT_START_HERE.md`
- agent execution philosophy → `Docs/Production/AGENTIC_STUDIO_OPERATING_MODEL.md`
- bounded inference-funding / paid-problem sidecar → `Docs/Strategy/PAID_PROBLEM_RADAR_BUILD_NOW_2026-09-10.md`

Core rules:

```text
OWNER SETS TARGET
→ cheapest proven reliable agent does the broad work
→ evidence establishes what is real
→ expensive/strong model handles only the hard remainder
→ cheap agent verifies/cleans up
→ owner/runtime/art judgment closes the milestone
```

Phone = production control room.  
Interactive Unreal workstation = truth machine.  
Git = infrastructure, not the product.  
Agent motion ≠ project progress.  
No runtime/art PASS without runtime/art evidence.

For a remote/mobile prep shift, prefer a `WHEN YOU SIT DOWN AT THE PC` landing strip that leaves the owner with the first concrete build/test/open-and-judge action instead of more Git archaeology.
