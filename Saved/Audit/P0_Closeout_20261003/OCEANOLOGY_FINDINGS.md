# Oceanology biolum vs MPC - findings (read-only, 2026-10-03)
ROOT CAUSE
- Biolum_Intensity is written ONLY as 1 + BeatPulse*1.5 (MelodiaAudioReactivePresentationSubsystem.cpp:137 MID, :156 reflected actor call). BeatPulse is the cos^2 music-clock lane (:314), no event term.
- DriveOceanBeatValues(World, BeatPulse, Combat, Impact) is called at :382 with no access to GlobalSparkleIntensity / QuantumPulse (palette lanes written by reactivity subsystem).
- MelodiaCymaticsWriterSubsystem.cpp:112-115 computes DrivenPulse = clamp(BeatPulse+0.6*max(Sparkle,Quantum),0,1.6) and publishes it ONLY to MPC_Cymatics_Driver (:124); the ocean never reads it.
- Master M_Water_Oceanology_Melodia: get_all_expressions shows NO CollectionParameter at top level; Biolum_* are scalar params feeding MF_WaterBioluminescence_v9. So the master cannot sample either MPC; MID writes are the only path.
