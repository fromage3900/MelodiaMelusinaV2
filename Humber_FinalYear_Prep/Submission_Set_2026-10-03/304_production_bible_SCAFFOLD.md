## 5. Pipeline and Workflow — DRAFT (your section; this is where your technical-art strength shows)
- **Tools and software:** Blender 5.2 (modelling, rigging, animation, VSE edit), Unreal Engine 5.8
  (real-time render, lookdev, sequencer), Substance Painter / Designer (texturing), Houdini
  (procedural geometry, if the team wants it). «Confirm the team's actual toolset before submitting.»
- **Asset management:** one naming convention across the team (`SM_`/`SK_`/`M_`/`T_`/`A_` prefixes,
  version suffix `_v01`), a single shared folder tree per stage (01_Preprod → 05_Edit), and one
  source-of-truth file per asset. A ready-made folder tree already exists in the repo at
  `Humber_FinalYear_Prep/Capstone_Pipeline_Scaffold/` — reusable for the group.
- **Workflow per stage:** model → rig → animate (blocking, then spline) → light → render → edit.
  Each stage hands off a locked file to the next so nothing is re-opened downstream.
- **File formats and delivery specs:** FBX for engine hand-off, PNG/EXR for renders, MP4 1080p24 for
  any cut delivered to the course (that is the ANMN submission standard).
- **Why this pipeline:** every stage is scriptable and reproducible. The same asset can be
  regenerated from source rather than hand-fixed, which is the difference between a team that
  recovers from a mistake in an hour and one that loses a week.
